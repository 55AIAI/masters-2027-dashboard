## Авторизация: статус и настройка

Реальный вход двух человек ещё **не активирован**: Supabase Project URL и publishable key намеренно пустые в `config.js`; найденный ранее Supabase-проект неактивен. Пока доступен только общий гостевой каталог, без личных данных.

Чтобы получить два независимых защищённых профиля:
1. Создать/подключить отдельный действующий Supabase-проект.
2. Применить [RLS SQL](../v8/schema.sql) и проверить все политики.
3. Пригласить ровно двух пользователей в Supabase Auth; выключить публичную регистрацию.
4. Добавить GitHub Pages URL в Auth redirect allowlist.
5. Вставить только public URL и **publishable key** в `config.js`.
6. Проверить два входа, сохранение и RLS до переноса личных JSON. Защищённость подтверждается **серверной RLS**, не кнопкой переключения профиля.

Более полная инструкция: [MULTIUSER_SETUP.md](../v8/MULTIUSER_SETUP.md).
