# МАГА — заявки в магистратуру 2027/28

Личный трекер поступления: программы, дедлайны, стипендии, требования к английскому, документы, задачи и «Болашак».

**Сайт:** https://55aiai.github.io/masters-2027-dashboard/

## Что нового в v11

- Табло ближайших сроков на главной: обратный отсчёт и время по Астане (UTC+5).
- По каждой программе видно, что покрывает финансирование (обучение и проживание), требования IELTS, взнос за подачу и дату последней проверки данных.
- Проверка английского: введите балл IELTS в «Профиле», и сайт покажет, каким программам он подходит.
- Счётчик Erasmus Mundus: форма DEAI требует подтвердить, что подано не больше трёх программ.
- Вид «Карточки» или «Таблица», фильтры «Полное покрытие», «Подходит по английскому», «Проверить данные».
- Календарь открывается на текущем месяце. Есть тёмная тема и мобильная навигация.
- Данные о программах сверены с официальными сайтами 16.11.2026.

## Личные данные

Публичный `index.html` больше не содержит профиль, номера заявок и переписку с рекомендателями. Они хранятся только в браузере (localStorage).

- Первый запуск на устройстве: **Профиль и данные → Импортировать JSON**, выбрать личный файл `maga-personal.json`. Этот файл не коммитить.
- Прогресс из прошлой версии (статусы, задачи, документы) подхватывается автоматически: используется тот же ключ localStorage.
- Перенос между устройствами: **Скачать JSON** → на другом устройстве **Импортировать JSON**.

Старые коммиты репозитория содержат прежние версии с личными данными. Новая версия историю не переписывает.

## Как обновлять данные

- `src/catalog.json` — каталог программ, календарь, задачи, документы, Erasmus, «Болашак».
- `src/app.html` — интерфейс (шаблон с меткой `/*__CATALOG__*/`).
- Сборка: `python3 src/build.py src/app.html src/catalog.json index.html`.

Поля программы, которые использует интерфейс: `deadline`, `deadlineTime` (например `12:00 GMT`, `15:00 Helsinki`, `23:59 CET`), `english` (`ielts`, `minBand`, `writing`, `moi`, `note`), `cover` (`tuition`/`living`: `yes`, `partial`, `cond`, `no`, `?`), `fee`, `verified`, `emjm`.

## Ограничения

- Сайт не связан с порталами вузов и почтой: статусы вносятся вручную.
- Справочник «Болашак» — снимок таблицы, а не официальный перечень 2027 года.
- Перед подачей сверяйте сроки и требования на официальных страницах.
- `v8/` и `v10/` — старые тестовые версии с авторизацией; основная версия — корневой `index.html`.
