# МАГА — Application OS 2027/2028

Интерактивный дашборд для планирования поступления в магистратуру: Erasmus Mundus, Болашак, университеты, дедлайны, документы и задачи.

## Сайт (GitHub Pages)

https://55aiai.github.io/masters-2027-dashboard/

Если страница показывает 404, включите GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

## Изменение приложения

- [index.html](index.html) — автономное приложение (HTML/CSS/JavaScript и встроенные справочные данные).
- Для изменения сайта откройте `index.html` на GitHub, нажмите **Edit** (карандаш), внесите изменения и сохраните коммит в `main`. При включённых Pages новое содержимое публикуется по той же ссылке.
- Чтобы работать локально, сохраните `index.html` и откройте его в браузере.

## Как сохраняется прогресс

Статусы, выполненные задачи, заметки и избранное хранятся **в localStorage текущего браузера**. GitHub Pages *не* синхронизирует их между устройствами и не записывает изменения в GitHub.

Для переноса: **Синхронизация → Экспорт JSON**, затем на другом устройстве **Импорт JSON**. Резервные копии могут содержать личные заметки — не коммитьте их в публичный репозиторий.

## Ограничения

- Данные о программах — справочный снимок на 13 ноября 2026 года. Проверяйте сроки и требования на официальных сайтах перед подачей.
- Не загружайте личные данные, паспорта, письма и admissions IDs в этот публичный репозиторий.
- Раздел «Болашак» основан на справочной таблице, а не на автоматической синхронизации или проверке актуального государственного перечня.
